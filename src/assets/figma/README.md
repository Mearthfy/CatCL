# Figma 导出素材

来源：https://www.figma.com/design/2JGeJzMs9yfqwqIZRd7b8Z/Untitled?node-id=3-60

- `avatar.svg`：Ellipse 1，节点 `3:5`。
- `minimize.svg`：Group 3，节点 `11:79`。
- `close.svg`：Group 2，节点 `11:78`。

这些 SVG 为 Figma MCP 返回素材的原始下载文件，未改绘；保存在项目中以避免远程素材链接过期。

设计尺寸来自外层背景 Rectangle 1（800 × 600），而非误设为 143 × 143 的父 Frame。空白卡片中的文字和功能沿用现有启动器；后续页面沿用相同颜色和组件样式。
